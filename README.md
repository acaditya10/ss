# Sumit Studio

Luxury wedding photography and cinematography studio website — Delhi NCR, India.

**Live:** https://ss.acaditya10.tech

## Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
- Motion (animation)
- Deployed on Vercel

## Development

```bash
npm install
npm run dev
```

## Scripts

| Command           | Description                |
| ----------------- | -------------------------- |
| `npm run dev`     | Dev server on port 3000    |
| `npm run build`   | Production build to `dist/`|
| `npm run preview` | Preview the production build |
| `npm run lint`    | TypeScript type check      |

## Deployment

Pushes to `main` deploy automatically via Vercel. Custom domain: `ss.acaditya10.tech`.
